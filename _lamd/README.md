# LaMD conversion of Network Performance Analysis

Canonical sources are the 2006–2007 files `lectureNotes.lyx` and
`lectureSlides.lyx`. Older per-lecture LyX files stay in the archive and are
not converted in parallel. `lectureNotes.tex` is stale (it stops before Burke,
Jackson, and ALOHA).

Lecture notes and slides are regenerated from `lectureNotes.lyx` and
`lectureSlides.lyx` by `python3 scripts/convert/run.py`. Generated snippets
live in `snippets/_npa/generated/{notes,slides}/`. Each `_lamd/*.md` lecture
includes both, so notes stay complete and slides come from the A4 FoilTeX deck
(split roughly two Reveal slides per original foil). See
`scripts/convert/README.md`.

Handwritten drafts remain in `snippets/_npa/includes/` until the conversion is
trusted. They are **not** copied into `lawrennd/snippets` yet. A symlink
`_lamd/snippets` → `../snippets` lets `maketalk` resolve local includes.

## Overlap with the central snippets repo

| NPA material | Central include |
| --- | --- |
| Joint / marginal / conditional, sum/product/Bayes | `_ml/includes/probability-review-compact.md` |
| Poisson PMF plot | `_ml/includes/poisson-distribution.md` |
| Pictorial probability diagram | regenerated by `mlai.plot.prob_diagram` inside the compact review's parent; NPA keeps the original height PDF/CDF figures locally |

Nigeria NMIS examples in `_ml/includes/probability-review.md` are MLAI-specific
and are **not** pulled into this course. Use the compact review instead.

## MATLAB → Python

See `python/README.md`. Erlang curves, exponential sampling, and the discrete
M/M/1 simulator are in `python/npa_plots.py`.

## Diagrams

Historic EPS/PDF figures used by converted lectures are rasterized to
`slides/diagrams/npa/` with Ghostscript (`png16m`). Remaining FIG/EPS files
can use the same route. Generated plots from central snippets write under
`slides/diagrams/ml/` and `slides/diagrams/mlai/` at compile time.

## Notebook smoke tests

From the repository root, after `pip install -r requirements-smoke.txt`:

```bash
python scripts/smoke_notebooks.py
```

See the root `README.md` for the subset flags and the GitHub Actions workflow.

`parking.md` is the overflow holding bay, not a lecture. When a live session
overruns, move leftover slides there and record them in the `parked:`
frontmatter list. Do not add `parking` to `lectures.csv`.

Compile from `_lamd/`:

```bash
chmod +x compile.sh
./compile.sh
```
